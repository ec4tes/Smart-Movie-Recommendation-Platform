# Smart Movie Recommendation Platform

Spring Boot, React, PostgreSQL ve TMDB entegrasyonu ile geliştirilen full stack bir film öneri platformudur.  
Proje, sprint bazlı ilerleme, detaylı GitHub issue yapısı ve modüler label sistemi ile yönetilmektedir.

## Kullanılan Teknolojiler
- Spring Boot
- React + TypeScript
- PostgreSQL
- TMDB API
- JWT Authentication

## Ana Modüller
- Kimlik Doğrulama ve Kullanıcı Yönetimi
- Film Kataloğu
- Puanlama, Favori ve Yorum Sistemi
- Öneri Motoru
- Analitik ve Admin Paneli

## Veri Analizi ve Öneri Sistemi
Proje içerisinde veri madenciliği ve analiz teknikleri kullanılarak kullanıcı davranışlarına göre öneriler üretilmektedir:

- Collaborative Filtering (kullanıcı bazlı öneri)
- Content-Based Filtering (içerik bazlı öneri)
- Trend ve popülerlik analizi
- Hibrit öneri sistemi (birden fazla yöntemin birleşimi)

Bu sayede kullanıcıların izleme alışkanlıklarına göre daha doğru ve kişiselleştirilmiş öneriler sunulmaktadır.

## Amaç
Profesyonel bir geliştirme süreci takip ederek ölçeklenebilir ve modüler bir film öneri sistemi geliştirmek.
